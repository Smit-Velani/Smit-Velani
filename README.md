## Projects

**[RAG PDF Chatbot](https://github.com/Smit-Velani/RAG-PDF-Chatbot)**
End-to-end RAG pipeline using LangChain and FAISS vector database. Processes PDF documents into 500-word overlapping chunks stored as 384-dim semantic vectors. Integrates Google Gemini 2.5 Flash API with custom prompt engineering for context-grounded answers.
`Python` `LangChain` `FAISS` `HuggingFace` `Gemini API`

**[Loan Default Prediction with MLflow](https://github.com/Smit-Velani/Loan-Default-Prediction-MLflow)**
Trained 4 ML models on 32,581 real loan records with all experiments tracked via MLflow. XGBoost achieved 93.4% accuracy and AUC 0.947. Identified loan grade, home ownership and loan percent income as top predictors.
`Python` `XGBoost` `MLflow` `Scikit-Learn` `Pandas`

**[Multi-Agent Atari Boxing with Deep Q-Learning](https://github.com/Smit-Velani/Multi-Agent-Atari-Boxing-DQN)**
Two competing DQN agents trained in Atari Boxing using PettingZoo and PyTorch over 200 episodes on T4 GPU. Achieved 62%/38% win-rate split. Implemented Experience Replay, Target Network and Epsilon-Greedy from scratch.
`Python` `PyTorch` `PettingZoo` `OpenCV` `Matplotlib`

**[DataPulse Dashboard](https://github.com/Smit-Velani/datapulse-dashboard)**
